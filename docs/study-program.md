# 대입 학습 보완 프로그램 (`/study`)

내신·모의고사 점수를 바탕으로 취약 단원을 진단하고,
기초–심화–응용 단계별 문제 풀이와 오답 복습까지 하나의 흐름으로 잇는 학습 앱입니다.

기존 FuelScope 대시보드와 완전히 분리되어 `/study` 경로 아래에서만 동작합니다.

---

## 2. 핵심 동작

### 취약점 진단 (`lib/study/diagnosis.ts`)

점수 하나만으로는 어느 단원이 약한지 알 수 없으므로 네 가지 신호를 합칩니다.

```
우선순위 = 대입 비중(0~5)
         + 직접 체크한 약점(+3)
         + 목표까지의 거리(0~3)
         + (1 − 실제 정답률) × 4
```

정답률은 해당 단원을 3문항 이상 푼 뒤부터 반영됩니다.
문항이 없는 단원은 추천해도 학습할 수 없으므로 순위에서 제외됩니다.

### 단계 배치와 승급 (`lib/study/mastery.ts`)

| 단원 정답률 | 시작 단계 |
|---|---|
| 0 ~ 50% | 기초 |
| 51 ~ 75% | 심화 |
| 76% 이상 | 응용 |

- 같은 단원 **3연속 정답 → 한 단계 승급**
- 같은 단원 **2연속 오답 → 한 단계 하향**
- 연속이 끊기면 카운터는 0으로 초기화됩니다.

### 문제 세트 조립 (`lib/study/assemble.ts`)

| 모드 | 구성 | 총 문항 |
|---|---|---|
| 20분 | 기초 5 + 심화 3 + 오답 유사 2 | 10 |
| 50분 | 기초 8 + 심화 7 + 응용 2 + 오답 유사 3 | 20 |

보충 우선순위:

1. 약점 단원 + 현재 단계의 DB 문항
2. **같은 과목의 같은 단계** — 단계를 단원보다 먼저 맞춥니다
3. 같은 단원의 다른 단계
4. 같은 과목 전체
5. 그래도 부족하면 **변형 문제 자동 생성** (`questions/templates.ts`)

- 최근 3일 안에 맞힌 문항은 새 문제로 다시 내지 않습니다(오답은 예외).
- 오답 노트가 비어 있으면 복습 자리를 새 문항으로 메워 세트 문항 수를 유지합니다.
- 최종 배열은 **난이도 오름차순**이라 첫 문항부터 어려워지는 일이 없습니다.

### 오답 복습 루프

틀린 문항은 즉시 오답 노트에 저장되고, 다음 세트에 "오답 유사" 자리로 다시 나옵니다.
**연속 2회 정답**이면 자동으로 해결 처리됩니다.
변형 문제도 복습할 수 있도록 문항 전체를 스냅샷으로 보관합니다.

### 학습 계획 (`lib/study/plan.ts`)

입력한 하루 가능 시간을 **절대 넘지 않습니다.**

```
가능 시간 ─┬─ 70% : 약점 단원 학습 세션 (50분/20분 단위로 절단)
           ├─ 20% : 오답 노트 복습
           └─ 10% : 자율 (EBS 등 외부 무료 자료)
```

## 3. 데이터 모델 (`lib/study/types.ts`)

| 타입 | 역할 |
|---|---|
| `Profile` | 학년, 목표, 과목별 목표 점수, 하루 가능 시간 |
| `Subject` / `Unit` / `Topic` | 교육과정 트리 (과목 → 단원 → 유형), 단원별 대입 비중 |
| `Question` | 본문·선택지·정답·단계별 풀이·핵심 개념·복습 개념 |
| `QuestionTemplate` | 숫자만 바꿔 변형 문항을 만드는 생성기 |
| `ScoreRecord` | 내신/모의고사 점수 + 직접 체크한 약점 단원 |
| `MasteryState` | 단원별 현재 단계, 연속 정답/오답 카운터 (승급 판정의 기준) |
| `Attempt` | 모든 풀이 기록 — 정답률·리포트의 원천 데이터 |
| `WrongNote` | 오답 노트, 해결 진행도, 메모, 문항 스냅샷 |
| `StudySession` | 진행 중인 세트, 답안, 문항별 소요 시간 |
| `DailyPlan` / `PlanItem` | 오늘 할 일과 완료 여부 |

## 4. 저작권 방침

- **기출 시험지 원문을 저장하거나 노출하지 않습니다.**
- 모든 지문·문항은 해당 유형을 연습하기 위해 새로 작성한 것입니다.
- 외부 자료(EBS, 평가원 등)는 복제하지 않고 자율 학습 안내로만 링크합니다.

---

## 5. 저장 방식

현재는 **브라우저 `localStorage`** 에 저장합니다 (키: `fuelscope.study.v1`).

- 로그인·서버 없이 즉시 동작하고 외부 비용이 들지 않습니다.
- 기기를 바꾸면 기록이 따라가지 않습니다 → 서버 DB 이관이 다음 단계입니다.
- 서버 렌더링 결과와 첫 클라이언트 렌더링을 일치시키기 위해
  `localStorage`는 마운트 이후에 읽고, 그 전에는 스켈레톤을 보여 줍니다
  (`lib/study/store.ts`).

이관 시 바꿀 곳은 `lib/study/storage.ts`와 `lib/study/store.ts` 두 파일이며,
도메인 로직(`diagnosis`, `mastery`, `assemble`, `plan`, `report`)은 순수 함수라
그대로 재사용됩니다.

---

## 6. 의도적으로 넣지 않은 기능

- 진로·적성 테스트 기반 대학/학과 추천
- 학부모 리포트
- 자퇴·검정고시 권유
- 대학 합격 예측

목표 점수는 합격 가능성 판정이 아니라 **오늘 무엇을 먼저 할지 정하는 기준**으로만 쓰입니다.
